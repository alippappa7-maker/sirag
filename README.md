# سراج (Siraj)

## نبذة عن المشروع
سراج منصة إسلامية عربية تساعد المستخدم على:
- إنشاء أفكار ومحتوى مرئي ومسموع.
- البحث عن المصادر وربط الادعاءات بالمراجع.
- إنتاج فيديوهات قصيرة.

## حالة المشروع الحالية (بداية الحزمة الثانية)
تم إنجاز الميزات التالية بنجاح:
1. **بنية التطبيق**: تصميم بنية `Clean Architecture` وتهيئة `Navigation` متقدم.
2. **نظام التصميم**: ألوان، خطوط عربية، تصميم متجاوب، و `Dark/Light Mode`.
3. **المصادقة والأدوار**: تسجيل الدخول، إنشاء الحسابات، وصلاحيات `Firebase`.
4. **نظام المشاريع**: إدارة المشاريع (إنشاء، حذف، أرشفة، تصفية)، محرر للمشروع مع حفظ تلقائي.
5. **الإعدادات والتفضيلات**: تفضيلات متكاملة (المظهر، المواقيت، الجودة، لغة، الخ) مزامنة سحابياً مع `Firestore`.
6. **استوديو المحتوى**: تم بناء النماذج المتقدمة، مساحات العمل، الخطة والسيناريو، نظام المصادر، القران والتفاسير، محرر المشاهد، ونظام طلب المراجعة والاعتماد.
7. **مدير الوسائط والبحث الخارجي**: مكتبة لإدارة الصور، الفيديو، الصوت، مع التحقق من التراخيص وحقوق النشر.
8. **توليد الصور بالذكاء الاصطناعي**: توليد بصري عالي الجودة مع ضوابط وفلاتر شرعية صارمة تمنع تجسيد الأنبياء والصحابة.
9. **الاستوديو الصوتي والتسجيل (Audio Studio)**: توليد تعليق صوتي فصيح عبر الخادم، رفع تسجيلات وتلاوات موثقة، قص البداية والنهاية، مزامنة مدة المشهد تلقائياً، والتمييز الشرعي الإلزامي لشارات التوليد والتلاوة.
10. **مكتبة الموسيقى والمؤثرات الصوتية (Soundtracks & SFX)**: مكتبة مرخصة لأصوات الطبيعة، المؤثرات الصوتية، الفوكالز البشرية، والموسيقى المرخصة مع تحكم كامل بالطبقات الصوتية وفلتر إلزامي لإخفاء الموسيقى واحترام رغبة المستخدم.
11. **نظام الترجمة والشارات للفيديو (Subtitles & Timing)**: محرر ترجمة متزامن مع المشهد، دعم RTL، تصدير SRT و VTT، خيار حرق الترجمة داخل الفيديو، قفل النصوص الشرعية لمنع التعديل، ودعم ترجمة المعاني إلى الإنجليزية مع مراجعة إلزامية.
12. **مشغل معاينة المشروع وفحص ما قبل التصدير (Project Preview & Quality Gate)**: مشغل معاينة لكامل مشاهد المشروع مع تبديل المقاسات (9:16, 16:9, 1:1)، مسطرة زمنية دقيقة، تحكم بالسرعة والصوت، وفحص آلي للموانع والتحذيرات الشرعية والتقنية قبل التصدير.
13. **طابور إنتاج الفيديو السحابي (Production Jobs & Cloud Tasks)**: معالجة سحابية غير متزامنة ومقاومة لانقطاع الواجهة، حساب الرصيد خادمياً، مفتاح عدم التكرار (Idempotency Key)، متابعة لحظية لنسبة التقدم، سجل أحداث آمن، استرداد الرصيد عند الفشل، وإمكانية إلغاء وإعادة محاولة المهام.
14. **موجز الومضات**: تمرير عمودي للومضات الموثقة فقط، مع تشغيل تلقائي وعرض بطاقة توثيق المصدر.
15. **نشر الومضات**: تدفق رفع ومراجعة الومضات مع تطبيق سياسات النشر والفحص التلقائي.
16. **التفاعل والسلامة المجتمعية**: إعجاب، حفظ، متابعة، إبلاغ، إخفاء محتوى وحظر، مع شاشة إدارة (Moderation).
17. **لوحة الإدارة**: إدارة المحتوى (اعتماد، تعليق، أرشفة) وتصنيفه مع سجل تدقيق لكل الإجراءات.
18. **الحماية وقواعد الوصول**: تأمين مركزي لـ Firestore و Storage باستخدام Firebase Security Rules و Custom Claims، مع حماية مسارات الدفع والتعديل من العميل.
19. **نموذج الاشتراكات والخطط**: نماذج قابلة للتوسع للاشتراكات والأرصدة والامتيازات (Entitlements) مع فصل كامل وتأسيس للتحقق الخادمي الآمن.
20. **الأرصدة وحدود الاستخدام**: نظام أرصدة يعتمد على حجز الرصيد وتأكيده خادمياً مع سياسة منع التلاعب واسترجاع الرصيد عند فشل العمليات المكلفة.
21. **اشتراكات Google Play**: دمج عمليات الشراء عبر متجر جوجل باستخدام `BillingClient` مع توثيق التحقق الخادمي الإلزامي لمنح الامتيازات وحماية `purchaseToken`.
22. **اشتراكات App Store**: التأسيس النظري والخادمي للربط مع StoreKit 2 ومعالجة اشتراكات iOS بإشعارات App Store Server Notifications V2.


## إعدادات طابور المهام السحابية (Cloud Tasks & Render Backend)
لإعداد طابور التصيير والإنتاج السحابي في بيئة الإنتاج:
1. تفعيل Cloud Tasks API في Google Cloud Console.
2. إنشاء طابور مهام الإنتاج: `gcloud tasks queues create video-render-queue --max-concurrent-dispatches=10`
3. تهيئة خدمة التصدير والتصيير على Cloud Run / Cloud Functions لربطها بـ `production_jobs` في Firestore.
4. التأكد من حفظ روابط التنزيل في Cloud Storage بروابط موقعة ومؤقتة (Signed URLs).

## إعدادات Firebase (هام جداً)
بناءً على سياسات الأمان، لم يتم تضمين أي مفاتيح سرية في الكود، وتم استخدام ملفات `dummy` لنجاح البناء. يجب عليك تنفيذ الخطوات التالية يدوياً لتشغيل تسجيل الدخول الفعلي:
1. أنشئ مشروعاً جديداً في [منصة Firebase](https://console.firebase.google.com).
2. قم بتفعيل **Authentication** واختيار مزودات (Email/Password و Google).
3. قم بتفعيل **Firestore Database**، ثم قم بنسخ محتوى ملف `firestore.rules` الموجود في المشروع ولصقه في تبويب Rules.
4. أضف تطبيق Android باستخدام الـ Package Name: `com.siraj.app`.
5. حمّل ملف `google-services.json`.
6. قم برفع ملف `google-services.json` إلى مجلد `app/` عبر واجهة AI Studio ليعمل النظام على بيئتك الخاصة.


## إعداد الخادم والأمان (Firebase Cloud Functions)

لضمان أعلى درجات الأمان وحماية المفاتيح، لا يقوم التطبيق بالاتصال المباشر بمزود الذكاء الاصطناعي. بدلاً من ذلك، يستخدم Firebase Cloud Functions كخادم وسيط.

### خطوات نشر الخادم:
1. تأكد من تثبيت أدوات Firebase CLI: `npm install -g firebase-tools`
2. سجل الدخول وانتقل لمجلد الخادم: `cd functions`
3. قم بتكوين سر Gemini في بيئة Google Cloud:
   `firebase functions:secrets:set GEMINI_API_KEY`
4. انشر الخادم: `npm run deploy`
